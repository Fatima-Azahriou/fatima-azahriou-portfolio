03 / Experience

Where I've made an impact

Building practical software for developers, with a focus on usability, integration, and reliable workflows.

Software Engineer II · Oracle

~3 YEARS

Core contributor to Oracle SQL Developer for VS Code, a database development extension with more than one million installs on the Visual Studio Marketplace.

  • Contributed to product features across the extension, taking work through implementation and refinement.
  • Built Connection Folders to help users organize database connections, using Java, TypeScript, VS Code Extension APIs, and RESTful services.
  • Designed and implemented drag-and-drop SQL generation, allowing users to drag database objects into a worksheet and generate CRUD statements.
  • Worked on an AI-assisted code review capability to identify PL/SQL code-quality issues.
